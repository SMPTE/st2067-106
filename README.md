# TC 35PM ST 2067-106 IMF - OPL - Essence Type Transform Macros

This is a project to track issues on ST 2067-106 for engineering document development work.
Publication includes:
- SMPTE Standard document
- Schema XSD

Please submit an [issue](https://github.com/SMPTE/st2067-106/issues) if you have a comment or suggestion.

Project details:
1. Title - 35PM-ST-2067-106-OPL-Essence Type Transform Macros
2. Description - 
This project develops the essence type transform macros for timed-text rasterization and immersive audio bitstream (IAB) conversion. The macros are part of the IMF OPL framework defined by ST 2067-100
3. Problem to be Solved -
Rasterized subtitles, forced narrative and caption burned in for theatrical and TV episodic releases is essential to the processing of IMF compositions. Rasterized timed-text must be generated in order to overlay textual content onto images.
The IAB conversion Macro is proposed in the IAB in OPL report, SMPTE ER 1005. It defines a target soundfield configuration (e.g. 7.1.4) and invokes an immersive audio renderer which might be external or as part of a macro. The resulting audio channels are available for output to file.
Automation using the IMF OPL framework requires the standardization of these essence type transform macros.
4. Project Scope -
Develop a standard for the IMF OPL timed-text rasterization and IAB rendering as a part of the IMF OPL document suite.
